Подключить Tuya

Вход через Smart Life / Tuya Smart. Облачный режим требует интернета. Токены сохраняются на сервере.

Smart Life / Tuya Smart → Я → ⚙️ → Аккаунт и безопасность → User Code внизу экрана. После подтверждённого входа код сохраняется на сервере для повторного входа.

При повторном входе можно оставить User Code пустым. Для другого аккаунта введите новый код.
