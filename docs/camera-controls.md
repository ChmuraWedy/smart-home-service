# Камера: референс Smart Life и доступные настройки

Референс пользователя: [Smart Life UI](https://chatgpt.com/share/6acbcaf4-425c-83ed-9cb5-7b8fb70d6327), добавлен 11 октября 2026 года. Общая ссылка показывает текстовый разбор пяти экранов Sleep Cam, а исходные изображения в доступной версии ссылки не загружаются. Ниже зафиксировано сравнение описания с функциями, которые выбранное подключение Sharing действительно возвращает для Sleep Cam. Состояния из референса не используются как текущие значения.

## Реализовано

- Прямой эфир: раскрываемый просмотр на главной плитке и плеер в подробной карточке; звук и полноэкранный режим доступны в стандартных элементах плеера.
- «Изображение и звук»: приватность, ночное видение, переворот, дата и время на видео, устранение мерцания.
- «Обнаружение и оповещения»: движение, чувствительность, обнаружение человека, ограничение области, звук и его чувствительность, сирена.
- «Запись и карта памяти»: запись камерой, режим записи, ёмкость и состояние карты, состояние форматирования.
- «Дополнительные параметры камеры»: оставшиеся доступные параметры, включая формат области, форматирование и сообщения устройства. У форматирования указано, что оно удаляет записи. Редактор области по изображению пока отсутствует.

Группы формируются из определений API конкретного устройства. Нет определения — нет кнопки; права на запись и допустимые значения сохраняются из API. Неизвестные параметры остаются доступными в дополнительном разделе. Общая кнопка «Применить» отправляет только изменённые значения через выбранное подключение.

Значения режимов проверены по [стандартному набору команд камер Tuya](https://developer.tuya.com/en/docs/iot/f?id=K9gf47qbzhnj3):

| Код | Подписи значений |
| --- | --- |
| `basic_nightvision` | `0` авто; `1` выключено; `2` включено |
| `basic_anti_flicker` | `0` выключено; `1` 50 Гц; `2` 60 Гц |
| `motion_sensitivity` | `0` низкая; `1` средняя; `2` высокая |
| `decibel_sensitivity` | `0` низкая; `1` высокая |
| `record_mode` | `1` по событиям; `2` непрерывно |

Перевод подписей не меняет код или тип команды. Незнакомые значения не переименовываются. Числовые показания карты продолжают использовать масштаб, сообщённый устройством; например, фактическая схема Sleep Cam возвращает `sd_status` с масштабом, отличным от стандартной документации. Мы не подменяем его предположением о состоянии карты.

## Требует отдельной реализации или дополнительного API

Описание референса также упоминает HD, Wi-Fi, скорость видео, сохранение кадра, двусторонний разговор, запись из плеера, расписание обнаружения, Messages, Cloud и Service Hall. Эти элементы не означают, что подключённый Sharing API предоставляет соответствующий интерфейс. В этой реализации кнопки для них не добавлены. Запись на карту камерой отличается от записи видео браузером; журнал нашего приложения отличается от архива событий и записей Smart Life.

Нужны отдельная проверка доступного API и реализация: выбор качества, двустороннее аудио, сохранение кадра/видео из плеера, редактор области по кадру, расписание обнаружения и просмотр архива камеры. Облачные сервисы и подписки Smart Life не представлены как настройки устройства.
